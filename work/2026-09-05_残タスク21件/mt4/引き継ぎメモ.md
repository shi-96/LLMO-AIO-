# FX Hybrid v5 MT4移植版｜引き継ぎメモと未検証項目

作成：2026-09-05 ／ 秘書
ファイル：FX_Hybrid_Core_v5_MT4.mq4（365行）

## 1. 何を作ったか

MT5版 FX Hybrid v5 の「採用構成」を、MT4（MQL4）で動く1ファイルのEAとして書き起こした。
納品資料に記載されている構成・数値はすべて入力値として同じ名前・同じ既定値で入れてある。

- 銘柄：GOLD / USDCHF / GBPUSD（チャートに乗せた銘柄で動く）
- 時間足：M15
- 時間帯：ニューヨークのみ GMT 13:00〜16:00（ロンドンは 0/0 で閉じてある）
- 利確：RR 2.0 固定
- リスク：有効証拠金ベースで1トレード0.5%
- 同時保有：1
- 出来高デルタ：SOFT（0.70でフル、0.55で半分、それ未満は見送り）
- 使わない機能（151ロジック・トレーリング・建て増し・部分決済・早期撤退・ATR連動・局面ルーター）は入力値として残したうえで既定OFF

## 2. MT5版から実際に書き換えた箇所

| 箇所 | MT5版 | MT4版 |
|---|---|---|
| 発注 | CTrade / OrderSend(MqlTradeRequest) | OrderSend()（7.5引数の旧形式） |
| 保有の数え方 | PositionsTotal / PositionSelectByTicket | OrdersTotal + OrderSelect(SELECT_BY_POS) |
| 銘柄情報 | SymbolInfoDouble / SymbolInfoInteger | MarketInfo() |
| 移動平均 | iMA でハンドルを取り CopyBuffer | iMA() が値を直接返す |
| 出来高 | iTickVolume / CopyTickVolume | iVolume() |
| 時系列 | CopyRates / CopyClose | Close[] High[] Low[] Open[] Time[] |
| 同期確認 | SymbolIsSynchronized | MT4に同等の関数がないため IsTradeAllowed と気配値の妥当性で代替 |
| 取引セッション確認 | SymbolInfoSessionTrade | MT4に同等の関数がないため MODE_TRADEALLOWED で代替 |

## 3. 必ず確認してほしい未検証項目

**この移植は、MT5版のソース（FX_Hybrid_Core_v5_FINAL.mq5）を直接読んで作ったものではない。**
納品資料に書かれた仕様から再構成している。したがって次の3点は、MT5版のソースと突き合わせるまで一致を保証できない。

### ① 132コア（TomCamp SMC）の判定条件 ← 最重要

資料には「構造の切り上げ／切り下げ」「オーダーブロック」「EMAの向き」「close[1] / close[2] / EMA[1] の確定足のみ」までしか書かれていない。
そこで移植版では次のように実装した。

- 構造：直近 StructureLook（20）本の高値・安値を確定足から取り、その更新（BOS）を見る
- オーダーブロック：直近 OB_Bars（3）本の実体レンジ
- 方向：EMA(50, CLOSE) の上下

**EMAの期間50は資料に記載がなく、こちらで置いた値である。** BOSの判定式、オーダーブロックの定義（実体か髭か、直近の逆行足に限るか）も同様。
ここが違うと約定が一致しない。MT5版ソースの該当関数と1対1で突き合わせること。

### ② 出来高デルタの計算式

資料には「直近8本のM1ティック出来高」「0.70でフル、0.55で半分」とあるが、
デルタの定義そのもの（何を分子・分母に置くか）は書かれていない。
移植版では `max(上昇足の出来高合計, 下降足の出来高合計) ÷ 全体` としており、0.5が拮抗、1.0が一方向になる。
MT5版が「上昇－下降 ÷ 全体」の符号付きで持っている場合、閾値の意味が変わる。

### ③ 同時保有リスク上限3%

資料に「EA側の設定ではなくポートフォリオ集計側の条件」と明記されている。
移植版でも実装していない。3銘柄を同時に回す場合、合計リスクの管理は口座側または別の仕組みで行う必要がある。

## 4. その他、MT4固有で注意すること

- **MT4のティック出来高はMT5と一致しない。** 出来高デルタはブローカー依存の指標であり、MT4/MT5間でも値が変わる。成績の完全一致は原理的に期待できない。
- **MT4のバックテストは実ティックに対応していない。** MT5の「Every tick based on real ticks」に相当するモードがなく、MT4のモデリングは生成ティックになる。同じ数字は出ない。
- **TimeGMT() はMT4にも存在する**が、ブローカーによって返る値が異なる場合がある。判定はGMT基準である前提を、必ずログで確認すること。
- GOLDのSLバッファ150ポイントは固定値である。通貨ペアとGOLDでpointの意味が違うため、USDCHF / GBPUSD ではこの値の妥当性を別途確認する。

## 5. 次の手順（推奨）

1. MetaEditorでコンパイルし、0 errors を確認する（構文は通る想定だが未実行）
2. MT5版ソースの Core132Signal 相当と VolumeDelta 相当を開き、上記①②を突き合わせる
3. 一致させたうえで、デモ口座のGOLD M15に乗せて1週間ログだけ取る
4. MT5版と同じ期間でバックテストし、取引数の桁が合うかを見る（完全一致は狙わない）

**この4段を通すまでは実弾に入れないこと。**
