## 当て方（Mac側）

```sh
cd ~/Claude
git apply --check /path/to/タスク管理md_追記.patch   # まず当たるか確認
git apply /path/to/タスク管理md_追記.patch
```

`--check` が通らない場合は、08:00 以降に同じ行が編集されています。
その場合はパッチを諦めて、`タスク管理md_追記文.md` の文字列を手で行末へ足してください。
どの行かは `id:` アンカーで一意に特定できます。

行がずれているだけなら、次でも当たります。

```sh
git apply -3 /path/to/タスク管理md_追記.patch
```
