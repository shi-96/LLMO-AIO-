## 6. このページに無いもの（そのまま公開する場合の欠落）

1. **申し込み・問い合わせの導線が1つもない。** ボタン・フォーム・リンク・電話番号・メールアドレスのいずれも存在しない。読んだ人が次に進む先がない。
2. **会社名・担当者名・所在地・連絡先がない。** 「AI Strategy Partners」はフッターの著作権表記のみ。特定商取引法の表示に必要な項目が揃っていない。
3. **スマホでプラン欄が2列のまま。** グリッドに画面幅の切り替えがないため、狭い画面で読みにくくなる。
4. **メタ情報がない。** description、OGP、favicon、canonical のいずれも未設定。SNSで共有してもカードが出ない。
5. **構造化データがない。** ページ自身が「構造化データ実装」を売っているのに、自分のページには JSON-LD が1件も入っていない。
6. **llms.txt がない。** 同じく、自分が売っている施策を自分に適用していない。
7. **金額の条件が書かれていない。** 「〜」の下限だけで、対象範囲・期間・税の扱いが未記載。

## 7. 直すなら優先順位

1. 問い合わせ導線を1つ置く（フォームかメールリンク）。これが無いと他をどれだけ直しても成果に繋がらない。
2. 事業者情報と特商法表記を足す。
3. プラン欄に画面幅の切り替えを入れて、狭い画面では1列にする。
4. description と OGP を入れる。
5. 自分のページに JSON-LD と llms.txt を置く。売っている施策の実物見本になる。

## 8. この仕様書の作り方について

HTML1枚を読み、配色・書体・余白・文言・数値を項目へ分解して表に起こした。
所要は10分程度で、外部の道具は使っていない。
1枚もののページであれば同じやり方が使える。複数ページのサイトでは、ページごとに同じ表を作り、共通の配色・書体を先頭にまとめる形になる。
